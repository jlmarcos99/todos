# Workflow

- Cuando el usuario pida desplegar un cambio, crea una rama `feature/<short-description-in-English>` con una descripción breve en inglés.
- Implementa y verifica el cambio en esa rama; no despliegues directamente a `master`.
- Abre un pull request (MR) de la rama `feature/...` hacia `master` en GitHub para que el usuario lo revise antes del despliegue.
